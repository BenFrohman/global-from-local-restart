\begin{abstract}
Standalone zero-sorry Lean 4 formalization (`Continuation.lean`, `GlobalFromLocalRestart.lean`) proving `Continuation.no\_finite\_last\_time\_of\_restart`: an abstract continuation theorem showing that any evolution system satisfying local existence with uniform step size below a ceiling, a priori ceiling preservation, and uniqueness cannot terminate at a finite maximal time T*.
\end{abstract}

\section{Scope, Scientific Honesty, and Non-Claim Boundary}
Proves the abstract conditional continuation lemma in Lean 4 with zero sorry; explicitly states that applying it to 3D Navier-Stokes requires supplying the a priori ceiling hypothesis independently.

`Continuation.no\_finite\_last\_time\_of\_restart` is an induction. If time 0 is

reached and every reached time extends by a positive step, then there is no

finite last reached time.

`Continuation.global\_of\_local\_restart` is that induction with the step taken

from a `LocalWitness`. The witness is an argument. It is not constructed from

smooth data.

This file does not contain a uniqueness hypothesis. It does not derive a cubic

sink. It is not an unconditional Navier-Stokes theorem.

Pinned toolchain: `leanprover/lean4:v4.30.0-rc1`.

git clone https://github.com/BenFrohman/global-from-local-restart.git
